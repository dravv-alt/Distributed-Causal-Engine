# E003-AM002 preregistered protocol

Question: can complete file time profiles, explicit metric qualification states, incident-centered retrieval and isolated temporal projections establish a trustworthy representation for subsequent RCA experiments?

Reference: original ZIP CSV rows, source-local UTC+08 day, exact label epoch/datetime agreement, explicit workbook cells, current official OpenRCA evaluator/generator source and independent semantic fixtures. Hypothesis: representation integrity can pass with UNKNOWN semantic entries, while inadequate incident evidence or ambiguous query associations can still restrict evaluator readiness. No accuracy/causal claim is measured.

Independent variables: four scenarios and every telemetry file/schema. Controls: all files and all nonblank labels/queries, no incident selection by root presence, no schema/name-based metric unit guesses, no future evidence at query cutoff, exact string preservation, original files read-only. Random seed null. Freeze configuration/source/environment before execution. Artifacts are new directories only.

Timestamp census: read each complete CSV sequentially, verify shape/header, test s/ms/us/ns against directory day plus fixed 3600-second profile allowance. Select a unique observed scale; mixed scales/ambiguous and malformed rows remain auditable, never repaired by magnitude guessing. Strict source-day mapping separately counts boundary rows. For values supporting no directory interpretation, record precision/invalid/range evidence and source pointers. Full-file status QUALIFIED requires unique scale and explicit conservation; unsupported or ambiguous files block A. Hash decompressed source bytes and retain ZIP CRC EOF verification evidence. Neighbour ordering/min/max/counts accumulated without storing whole files.

Incident audit: all 335 current annotations (actual count verified). Fixed closed retrieval window [fault-300s,fault+300s], separately report before, exactly-at, and after. Telemetry selection depends only on scenario/time windows, never root component; root presence is checked only in an evaluator pass. The after segment is retrospective coverage only. Inference at fault time permits only [fault-300s,fault], with no post-fault observations. Missing sampled points exactly at fault are not failures alone. Full scan retrieves all available rows in these windows; overlapping windows share one stored source row. Resolve trace parents only from context available within the permitted query window; never pull future spans. Explicit unresolved states permitted. Workbook relations with unknown temporal validity are retained for audit but excluded from time-qualified inference.

Query association: inspect the official evaluator/generator, preserve their source version/hash/reference. Match scoring-point elements against label fields plus explicit query date/window only where uniquely supported. Do not join by row count/order, invent an incident interval, or feed scoring points into inference. UNKNOWN associations are recorded and block claims about official query scoring; do not turn coverage completeness into RCA task readiness.

Metrics: inventory every source metric, scenario/schema and count. Registry status QUALIFIED requires explicit documented evidence for each asserted semantic; otherwise UNKNOWN with null evidence and zero confidence. UNKNOWN is acceptable to E if no fabricated semantics occur. Numerical transformations requiring known units/temporality remain unavailable. Distinguish representation qualification from feature qualification.

Leakage: allowlist projection omits all raw text, source paths, incident/fault/query IDs, injection metadata and answer-bearing attributes. Source resource/metric/trace identities remain in provenance but are replaced with deterministic opaque tokens for inference. Audit source identifier cues and report removals. Actual metric values/raw span durations may be available only at observation time; unknown duration unit does not generate an end time. Every trace edge requires both supporting spans within the observation window. Window identifiers are evaluator-owned handles, not features. Label mutation must not change inference evidence for a fixed window. Log text excluded pending separate policy.

Coverage gate F measures complete incident coverage records and source conservation, with adequacy statuses per case. It does not require every label to be observable. Overall representation PASS may coexist with cases unsuitable for RCA; report denominator and exclusions without selecting favorable incidents. G requires operational projections label-isolated, bounded by cutoff and source cues removed, with query association reported honestly. If unresolved associations prevent the proposed next task, report restricted readiness rather than an unconditional all-purpose PASS.

H: build two independent projected replays from retained incident-centered source rows; compare per-case canonical/graph hashes. Full-file timestamp census executes once with byte hashes/CRC; deterministic projection is replayed twice. Separate census integrity from replay equality. Measure runtime, throughput, peak process memory and disk. Stop on disk safety limit; checkpoint completed file profiles and retain partial evidence. No full canonical expansion of 64 GiB data.

Gate decisions A-H use the user's revised table. PASS requires all conditions for the declared scope; FAIL/PARTIAL/NOT TESTED remain distinct. Stop after report/decision for human review. No RCAEval or raw-data deletion automatically follows a mechanical pass.
