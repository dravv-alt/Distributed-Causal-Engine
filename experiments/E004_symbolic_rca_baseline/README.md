# E004: symbolic RCA baseline

Plain language: we know which components were observed and some calls between them. A deliberately weak rule ranks components depended on by more other observed components. We compare it with rankings that ignore calls. This tests a structural prior, not whether telemetry proves a component faulty.

Read `protocol.md` and `hypothesis.md` before code; `configuration.yaml` identifies the fixed scope. Registration is in the new root experiment-index amendment and machine registration. E003's evidence is never rewritten.

All 335 oracle-time-conditioned cases are retained. Raw archives are not accessed. Unknown metric semantics prohibit making up failure symptoms. No training, model tuning, neural processing, RCAEval, official-query-score claim, causal inference or remediation.

Execution artifacts belong to `results/E004-R001/`. Final reports are proposals for human review, not self-approved gates.
