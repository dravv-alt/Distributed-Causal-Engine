# Hypothesis

A shared per-service scorer that receives local features and one-hop topology summaries will accept valid service sets of size 8, 12, and 20 and retain useful root-localization quality when trained only on eight-service scenarios. A strict fixed-eight baseline will reject size, ID, or order mismatches instead of silently assigning scores to the wrong services.

This hypothesis concerns a synthetic graph generator and a proposed architecture. It does not predict real DCE effectiveness.
