# Reasoning semantics

Facts contain kind, arguments, event interval, uncertainty, source observation references, rule ID and version.
Neural scores and explicit breaches generate candidates. Dependency paths, ordering and observed contradictions
shape explanations; no cause timestamp may be manufactured from processing time.

Absence of an observation is unknown, not healthy. A healthy-intermediate contradiction requires sufficient
coverage of relevant metrics and the relevant interval. Define sustained breaches in event time, not merely count of arrivals.
Onset intervals must preserve neural-versus-SLO provenance. Rules using uncertainty must specify interval comparison.

Return supporting and contradicting evidence, alternative root sets and explicit abstention reasons.
Ranking scores are not calibrated probabilities. Version all rules/fusion parameters and test both branches' contribution.
The R0 implementation is a baseline to audit against these semantics, not proof that all requirements are satisfied.
